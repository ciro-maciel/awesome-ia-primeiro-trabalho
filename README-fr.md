## Droits de ceux qui débutent

- [Lei do estágio](https://go.mymarketing.click/iaprim-lei-do-estagio) - La loi 11.788/2008, avec les droits du stagiaire. `officiel` `gratuit`
- [Lei do vale-transporte](https://go.mymarketing.click/iaprim-lei-do-vale-transporte) - La loi 7.418/1985, qui crée le titre-transport. `officiel` `gratuit`
- [Tabela de contribuição do INSS](https://go.mymarketing.click/iaprim-tabela-de-contribuicao-do-inss) - Part du salaire versée à l'INSS, selon le barème officiel. `officiel` `gratuit`
- [Tabelas do Imposto de Renda 2026](https://go.mymarketing.click/iaprim-tabelas-do-imposto-de-renda-2026) - Part du salaire versée à l'impôt sur le revenu, selon le barème officiel. `officiel` `gratuit`

## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand elle vient de l'organisme qui fixe la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la façon de l'intégrer. Les entrées avec l'étiquette "de l'auteur" sont réalisées par Ciro Cesar Maciel et suivent les mêmes règles que les autres.
