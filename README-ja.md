## ラベル

各項目には内容が書かれています。隣のラベルが選ぶ助けになります: 公式は標準を定める側から提供されるもの、オープンソースはコードが公開されているもの、無料か有料かは利用モデルによる、APIとSDKは連携方法による。「作者による」ラベルの項目は Ciro Cesar Maciel が作成したもので、他のすべての項目と同じルールに従います。
